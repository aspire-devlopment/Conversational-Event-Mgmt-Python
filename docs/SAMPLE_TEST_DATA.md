## Usage Notes

- These examples are written for the conversational chat session flow.
- You can paste the full block as one message or send the details step by step.
- Valid roles from the seed data are `Admin`, `Manager`, `Sales Rep`, and `Viewer`.
- Valid statuses are `Draft`, `Published`, and `Pending`.
- Make sure the start time is before the end time.
- Make sure the vanish time is later than the end time.
